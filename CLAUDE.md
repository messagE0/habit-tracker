# Память проекта: трекер привычек

Итоги разговоров с владельцем проекта. Claude читает этот файл в начале каждой сессии.

## О владельце и общении

- Общаемся на русском, простыми словами, без сложных вопросов.
- Владелец пока «вайбкодит» — учится и делает проект с помощью Claude.
- Пользуется Windows и PowerShell. Проект лежит в `C:\Users\<имя>\habit-tracker`.
- **Ничего не отправлять на GitHub (git push) без прямой команды владельца.** Коммитить локально можно.
- Плагин ponytail к проекту не относится, его не упоминать и не добавлять в настройки проекта.

## Цель

- Сейчас приложение личное, в будущем владелец хочет сделать его публичным.
- Главное — «серьёзное» выполнение привычек: нельзя ставить и убирать отметки задним числом.
- Хочется пользоваться приложением долго, поэтому нужен календарь и статистика.

## Что уже сделано

Всё в одном файле `index.html` (HTML, CSS, JS без библиотек, данные в localStorage, ключ `habits-v1`).

- Отметить можно только сегодняшний день. Прошлые дни заблокированы, пропуски показаны красным ✕.
- Снять сегодняшнюю отметку пока можно (на случай ошибки). Владелец не решил, оставлять ли это.
- Нажатие на название привычки открывает календарь по месяцам (от месяца создания до текущего) с итогом за месяц.
- Под календарём статистика: серия, рекорд, всего дней, процент за всё время. Неотмеченное сегодня не считается пропуском.
- Дата создания привычки берётся из её `id` (это `Date.now()` при создании).
- README на русском со списком планов.
- Расписание (`habit.schedule`: daily / weekdays / weekly с `n`). У старых привычек поля нет — это «каждый день». Будни: выходные не пропуски и не рвут серию. «N раз в неделю»: недели пн–вс, серия и рекорд считаются в неделях; неделя создания и текущая неделя штрафа не дают. Расписание можно выбрать только при создании, менять потом нельзя.
