# Трекер привычек

Простой трекер привычек в браузере: отмечай каждый день и не ломай серию 🔥

## Возможности

- **Привычки.** Добавляй и удаляй привычки, например «читать 20 минут».
- **Последние 7 дней** у каждой привычки и текущая серия выполнения подряд.
- **Честные отметки.** Отметить можно только сегодняшний день, прошлое изменить нельзя. Пропущенные дни показываются красным крестиком ✕.
- **Расписание.** При добавлении выбери: каждый день, по будням или от 1 до 6 раз в неделю. Необязательные дни не считаются пропусками. Для «N раз в неделю» серия и рекорд считаются в неделях (пн–вс), а цифра серии в списке зелёная.
- **Календарь.** Нажми на название привычки, чтобы открыть календарь по месяцам и увидеть, сколько дней в месяце выполнено (в днях и процентах).
- **Без регистрации.** Все данные хранятся в твоём браузере.

## Как запустить

Открой файл `index.html` в любом браузере. Устанавливать ничего не нужно.

## Установка на телефон

Приложение можно поставить как обычное: иконка на экране и работа без интернета. Для этого оно должно лежать в интернете по https (например, на GitHub Pages). С диска (`index.html` двойным щелчком) установка не работает, но всё остальное работает как раньше.

Данные хранятся в браузере каждого устройства отдельно. Привычки с компьютера на телефоне не появятся, пока не будет пункта «Аккаунт и синхронизация».

## Технологии

Основное приложение — один файл `index.html`: HTML, CSS и JavaScript без библиотек. Для установки на телефон рядом лежат `manifest.webmanifest`, `sw.js` (офлайн-режим) и иконки `icon-*.png`.
