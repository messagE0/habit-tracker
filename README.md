# Трекер привычек

Простой трекер привычек в браузере: отмечай каждый день и не ломай серию 🔥

## Возможности

- **Привычки.** Добавляй и удаляй привычки, например «читать 20 минут».
- **Последние 7 дней** у каждой привычки и текущая серия выполнения подряд.
- **Честные отметки.** Отметить можно только сегодняшний день, прошлое изменить нельзя. Пропущенные дни показываются красным крестиком ✕.
- **Календарь.** Нажми на название привычки, чтобы открыть календарь по месяцам и увидеть, сколько дней в месяце выполнено (в днях и процентах).
- **Без регистрации.** Все данные хранятся в твоём браузере.

## Как запустить

Открой файл `index.html` в любом браузере. Устанавливать ничего не нужно.

## Планы

- [x] Отметки только за сегодня
- [x] Календарь по месяцам
- [x] Статистика: серия, рекорд, всего дней, процент за всё время
- [ ] Расписание: по будням или N раз в неделю
- [ ] Напоминания и установка на телефон
- [ ] Аккаунт и синхронизация между устройствами

## Технологии

Один файл `index.html`: HTML, CSS и JavaScript без библиотек.
